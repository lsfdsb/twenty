## Crie um painel
Abra **Dashboards**, crie um painel e dê um nome ligado à sua finalidade. Organize-o em abas e adicione widgets. Cada widget precisa de uma fonte de dados e uma configuração de cálculo.

## Comece por três perguntas
- Quanto há no pipeline aberto?
- O que está previsto para fechar neste mês?
- Quais tarefas estão vencidas e quem é responsável?

Use números agregados para totais, barras para comparações e linhas para evolução. Texto pode explicar a definição de uma métrica; um gráfico não substitui essa definição.

## Defina o cálculo
Documente o objeto, o campo, a agregação, o período, os filtros e o fuso horário. Contagem de oportunidades e soma de valores respondem perguntas diferentes. Valores sem moeda compatível não devem ser somados diretamente.

## Limites da leitura
Os resultados refletem os registros disponíveis e as permissões. Dados de exemplo podem afetar totais: exclua-os das visualizações usadas para decisões. Exportação de dashboard e compartilhamento público não devem ser presumidos; use apenas os controles disponíveis no seu ambiente.
