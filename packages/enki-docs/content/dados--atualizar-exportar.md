## Atualizar por importação
Use um identificador único, como o ID do registro, para indicar o que deve ser atualizado. Confirme as regras de correspondência e os campos mapeados no importador. Uma planilha sem identificador confiável pode criar duplicados.

Antes de um lote grande, exporte uma cópia e teste poucas linhas. Não inclua colunas vazias que você não pretende alterar.

## Exportar
Abra a visualização desejada, confira os filtros e use a ação de exportação disponível. Verifique se a exportação considera os registros selecionados ou a visualização inteira. Respeite as permissões e mantenha arquivos com dados pessoais em locais controlados.

## Erros comuns
| Sintoma | O que conferir |
| --- | --- |
| Domínio duplicado | Registro existente e formato da URL |
| Relação vazia | Importação prévia da empresa e identificador usado |
| Opção inválida | Valores de API do campo de seleção |
| Coluna ignorada | Mapeamento da coluna para o campo |
| Valor incorreto | Separador decimal, moeda, data e fuso horário |

Guarde o resultado da importação para saber quais linhas foram aplicadas. Corrija apenas as que falharam antes de reenviar.
